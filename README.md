# Netflix Movies and TV Shows — Exploratory Data Analysis (EDA)

## 📌 Project Overview

This project performs Exploratory Data Analysis (EDA) on the Netflix Movies and TV Shows dataset using Python.

The objective of this project is to understand Netflix's content library by analyzing Movies and TV Shows based on content type, ratings, release years, countries, and genres.

The analysis includes data cleaning, exploratory analysis, KPI calculation, and data visualization to identify meaningful patterns and insights.

## 🎯 Project Objectives

- Understand the structure and characteristics of the Netflix dataset.
- Clean and prepare the data for analysis.
- Analyze the distribution of Movies and TV Shows.
- Analyze content ratings.
- Examine content trends by release year.
- Identify the countries with the highest representation.
- Analyze popular countries.
- Compare Movies and TV Shows across different categories.
- Extract meaningful insights from the data.

## 🔍 Key Findings

- Movies represent the majority of titles in the dataset.
- The United States has the highest representation among the analyzed countries.
- TV-MA is one of the most frequently occurring content ratings.
- Netflix's content library shows significant growth in titles released during recent years.
- Movies generally have a larger representation than TV Shows across the major countries analyzed.
